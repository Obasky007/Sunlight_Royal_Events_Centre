# Sunlight Royal Event Centre

A modern, conversion-focused website concept built for **Sunlight Royal Event Centre, Ibadan**.

This project was designed to present the venue clearly online and make it easier for potential clients to view the hall, understand available services, and make enquiries quickly through WhatsApp.

## Purpose

Many event venue enquiries start online. Before making a call, people usually want quick answers to questions like:

- What does the venue look like?
- What kind of events does it host?
- What facilities are available?
- Where is it located?
- How can I make an enquiry quickly?

This website was built to answer those questions in a simple, clear, and mobile-friendly way.

## Features

- Premium hero section with strong first impression
- Quick venue highlights and trust indicators
- Event hall gallery
- Features and amenities section
- Booking-focused call-to-action
- WhatsApp enquiry integration
- Location and directions
- Fully responsive layout for mobile, tablet, and desktop


## Project Goal

The goal is not just visual design.

It is to help turn online visitors into enquiries and bookings by making venue information easier to access and faster to understand.
